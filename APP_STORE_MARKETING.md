- Appear in location-based searches
- Showcase client reviews and ratings
- Track your practitioner SANA Index score
- Analytics dashboard to optimize your practice

💰 **Simple Payment Management**
- Automatic payment processing via Stripe
- Transparent 90/10 revenue split (you keep 90%)
- Direct payouts to your bank account
- Invoice generation and payment history

**FEATURES:**

✅ Comprehensive health questionnaire

## 📋 App Store Submission Checklist

### Pre-Submission
- [ ] All features tested on physical devices
- [ ] No crashes or critical bugs
- [ ] Privacy policy URL active
- [ ] Terms of service URL active
- [ ] Support email responding
- [ ] App icons generated (all sizes)
- [ ] Splash screens configured
- [ ] Screenshots captured (7 images)
- [ ] App description written
- [ ] Keywords optimized
- [ ] Age rating determined

### iOS Specific
- [ ] Apple Developer account ($99/year)
- [ ] Bundle ID registered (com.sana.wellness)
- [ ] Certificates and provisioning profiles
- [ ] TestFlight beta testing complete
- [ ] Compliance with App Store Review Guidelines
- [ ] Health Data Usage description in Info.plist
- [ ] Face ID/Touch ID usage description
- [ ] Location usage description (if using)
- [ ] Camera usage description (for profile photos)

### Android Specific
- [ ] Google Play Developer account ($25 one-time)
- [ ] Application ID (com.sana.wellness)
- [ ] Signed APK/App Bundle
- [ ] Google Play Console setup
- [ ] Closed/Open testing complete
- [ ] Privacy Policy URL in Store Listing
- [ ] Data Safety section completed
- [ ] Content rating questionnaire

### Data Collected
- Name, Email, Phone

- Payment processor (Stripe)

- Access data
- Export data
- Delete account
- Opt-out of marketing
